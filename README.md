# PROSTI — портфолио Артёма Суркова

Персональное портфолио дизайнера и разработчика: UI/UX, Web Design, Web Development, App Design.
Стиль — монохромный экспериментальный брутализм, distorted editorial.

Статус: этап 0A — документация и арт-дирекшн. Код ещё не написан.

## Документы
- `BRIEF.md` — ТЗ заказчика, источник истины.
- `REFERENCE.md` — текстовый разбор визуального референса (`IMG_6558.jpeg`).
- `DESIGN.md` — дизайн-система, движение, адаптив, архитектура, страницы.
- `ASSETS.md` — промпты для генерации фото и видео.
- `AGENTS.md` — правила для агентов.
- `PROGRESS.md` — журнал работы.

## Стек (план)
Vite, React, TypeScript, React Router (basename `/PROSTI/`), GSAP + ScrollTrigger, Lenis, OGL.
Деплой: GitHub Pages через GitHub Actions.

## Страницы
Home, About, Works, Project Detail, Services, Contact, 404.
