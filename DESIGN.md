# DESIGN — дизайн-система портфолио Артёма Суркова

Рабочее имя системы: **SURKOV / PRINT ERROR**.
Направление: monochrome experimental brutalism, distorted editorial.
Источник требований: `BRIEF.md`. Визуальный разбор: `REFERENCE.md`. При конфликте побеждает BRIEF.

Идея в одной строке: **сайт как плохо отпечатанный журнал очень хорошего арт-директора.**
Бумага, ксерокс, полутон, жирный гротеск, вырезанные фигуры. Цвета нет. Дисторшн — как сбой печати,
а не как фильтр из Instagram.

---

## 1. Принципы

1. **Чёрный, белый, бумага.** Ни одного цветного пикселя. Даже фокус-кольцо и выделение текста монохромны.
2. **Шкала решает.** Контраст размеров 1:20 и больше: заголовок 200px рядом с подписью 10px.
3. **Линия 1px — каркас.** Сетка видима через тонкие горизонтали, а не через карточки и рамки.
4. **Коллаж, а не галерея.** Фото вырезаны по контуру, перекрываются, заходят за край, лежат под углом.
5. **Пустота дорогая.** Большие поля между группами. Плотность — только внутри группы.
6. **Дисторшн дозирован.** Один главный эффект на экран. Всё остальное — тихое.
7. **Каждая анимация обратима.** Scrub по скроллу: вниз — вперёд, вверх — назад.
8. **Честность.** Концепты подписаны `CONCEPT`. Нет выдуманных клиентов, цифр, отзывов, контактов.

Запреты: градиенты, стекло, мягкие тени, скругления > 0, иконки-эмодзи, бейджи «New», карточки
с одинаковыми отступами в ряд по три, центрированные симметричные hero, стоковые улыбки.

## 2. Цвет (монохромные токены)

```css
:root {
  /* поверхности */
  --paper:        #EDEBE6; /* основной фон: тёплая бумага, не чистый белый */
  --paper-2:      #E2DFD8; /* вторичная поверхность, полосы, hover строк */
  --paper-3:      #D3CFC6; /* грязная ксерокопия, подложки фото */
  --white:        #F8F7F4; /* бумага на бумаге: вкладыши, форма в фокусе */

  /* чернила */
  --ink:          #0B0B0B; /* основной текст и плашки; не #000 — печать не бывает идеальной */
  --ink-2:        #2A2A2A; /* вторичный текст на бумаге */
  --ink-3:        #6B6B6B; /* микроподписи, метаданные (контраст 4.9:1 на --paper) */
  --ink-4:        #9A9792; /* только декоративные элементы, не текст */

  /* инверсия */
  --void:         #0B0B0B; /* чёрные плашки, футер, видеосекция */
  --on-void:      #EDEBE6;
  --on-void-2:    #A3A19C;

  /* линии */
  --rule:         #0B0B0B;              /* 1px линия на бумаге */
  --rule-soft:    rgba(11,11,11,.18);   /* второстепенные разделители */
  --rule-void:    rgba(237,235,230,.22);

  --selection-bg: #0B0B0B;
  --selection-fg: #EDEBE6;
}
```

Правила:
- Текст на бумаге: только `--ink`, `--ink-2`, `--ink-3`. `--ink-4` для текста запрещён.
- Чёрные плашки (`--void`) — максимум 2 на страницу. Это события, не фон.
- Фото всегда обесцвечены на этапе ассета, а не CSS-фильтром. CSS `grayscale(1)` — только страховка.
- Зерно накладывается поверх всего сайта одним слоем (см. §8.1). Плоский цифровой белый запрещён.

- Висячая пунктуация и `text-wrap: balance` для h1–h3, `text-wrap: pretty` для body.
- Цифры в Mono — `tabular-nums`.
- Микроразметка-подпись: `[ 02 ] / ABOUT`, `FIG. 03 — CONCEPT`, `↗` для внешних ссылок.

## 4. Сетка и пропорции

- **Desktop ≥1024:** 12 колонок, поля `clamp(16px, 2.5vw, 40px)`, гаттер 16px. Контейнер на всю ширину, без max-width у фона; текстовые блоки ограничены 62ch.
- **Tablet 768:** 8 колонок, поля 24px.
- **Mobile 375/390:** 4 колонки, поля 16px, гаттер 12px.
- Базовый модуль: **8px**. Вертикальный ритм секций: `--gap-section: clamp(96px, 14vw, 240px)`.
- Пропорции фото: 4:5 (портрет), 3:4 (фигура в рост), 16:9 (кино), 1:1 (объект). Других нет.

### Отступы

```
--s-1: 4px   --s-2: 8px   --s-3: 12px  --s-4: 16px  --s-5: 24px
--s-6: 32px  --s-7: 48px  --s-8: 64px  --s-9: 96px  --s-10: 144px  --s-11: 240px
```
Внутри группы — `s-2…s-5`. Между группами — `s-8…s-11`. Среднего «24 везде» не бывает.

### Асимметрия

- Текст и изображение никогда не делят ширину пополам. Типовые сплиты: 7/5, 8/4, 3/9, 2/7/3.
- Минимум один элемент на экран нарушает сетку: выходит за край, перекрывает линию, смещён на полколонки.
- Плавающие изображения: поворот от -6° до 7°, никогда 0° у всех сразу; z-слои 1–4.
- Линии 1px идут на всю ширину вьюпорта, даже когда контент в колонках.
- Подписи к фото — Mono 11px, стоят не под фото, а сбоку или в углу с отступом 8px.

### Компоненты-примитивы (не карточки)

- **Rule-row:** строка списка между двумя линиями 1px: индекс Mono слева, текст, `↗` справа. Hover: строка инвертируется полосой `--ink` снизу вверх (clip-path), текст сдвигается на 12px.
- **Text-button:** жирный Display-текст с подчёркиванием 2px. Hover: подчёркивание уезжает вправо и возвращается слева; буквы получают лёгкий displacement. Прямоугольных кнопок нет. Мин. хит-зона 44×44.
- **Cut-out:** вырезанная фигура (PNG/WebP с альфой) + жёсткая тень-копия `--ink` со смещением 6px и halftone-маской (не blur).
- **Plate:** чёрная плашка с выходящим за края белым мега-словом.
- **Field:** поле формы — только нижняя линия, лейбл Mono над ним, ошибка Mono под ним.

## 5. Фотостиль

Единый художественный ряд: **«фотокопия редакционной съёмки 1990-х»**.

- Ч/б, жёсткий контраст, глубокий чёрный без деталей в тенях, пересвеченный светлый фон.
- Зерно плёнки ISO 3200, следы ксерокса: полосы тонера, смазанные края, мелкий halftone в полутонах.
- Люди: в необычных образах — капюшоны, длинные пальто, маски из ткани, тени поперёк лица. Без улыбок
  в камеру, без крупных узнаваемых лиц (это не реальные люди и не заказчик).
- Архитектура: бетон, лестницы, брутализм, руины, пустые подземные переходы.
- Объекты: ноутбук, телефон, CRT, сканер, бумага — инструменты дизайнера как скульптуры.
- Обработка в вёрстке: силуэт вырезан маской; поверх — общий слой зерна сайта.
- **Нет фото Артёма.** Портрет About — анонимная фигура со спины / в тени, подписан `FIG. — STAND-IN`.
  Место для реального фото вынесено в конфиг.

Промпты — в `ASSETS.md`. Ассеты лежат в `public/media/`.

Форматы: AVIF + WebP, `srcset` 640/1080/1600/2400, `loading="lazy"` кроме hero, явные `width/height`.
Вырезанные фигуры — WebP с альфой (AVIF с альфой как первый `source`).

## 6. Дисторшн — техники и места применения

Правило: **один главный эффект на экран, один тихий фоновый**. Эффект всегда завязан на действие
(скролл, hover, переход). Нет постоянно дёргающихся элементов.

| Техника | Где | Как |
|---|---|---|
| **SVG `feTurbulence` + `feDisplacementMap`** | Hover на фото в Works, hover на text-button, переходы заголовков | Фильтр в `<svg>` со `scale` 0 → 40 → 0 на hover (GSAP tween атрибута), `baseFrequency` 0.012–0.02, `numOctaves` 2. Только на элементе под курсором. Safari: на `<img>` внутри `<svg><image>` или на обёртке; проверить. |
| **WebGL (OGL) — плоскость с шейдером** | Hero-объект Home, обложки проектов при скролле, переход между страницами | Одна канва на страницу. Фрагментный шейдер: смещение UV по noise × `uVelocity` скролла + RGB-нет — **монохромный** сдвиг яркости, без хроматики. Прогресс скролла → `uProgress` (scrub). Если WebGL нет или reduced-motion — статичное `<img>`. |
| **Canvas 2D halftone** | Портрет About, плашка Contact | Фото перерисовывается точками растра; размер точки = функция скролла (scrub). Проявление «из растра в фото» обратимо. |
| **CSS** | Микроэффекты повсюду | `clip-path` mask reveal, `transform: perspective() rotateX/Y` для плавающих объектов, `filter: blur()` в blur-transitions (только на коротких элементах, не на канве), `mix-blend-mode: difference` для курсора на `--void`. |
| **Split text + skew** | Заголовки | Буквы/строки въезжают из маски `overflow: clip` с `skewY` и `scaleY 1.4 → 1`, scrub. |
| **Video scroll** | Секция «Process» на Home | См. §7.3. |

Глобальный слой зерна: один `<canvas>` или SVG-noise PNG 256×256 с `background-repeat`, opacity 0.08,
анимация смены кадра 8 fps через `steps()`. На reduced-motion — статичный.

## 7. Движение

### 7.1 Тайминги и кривые

```
--ease-out:   cubic-bezier(.16, 1, .3, 1)    /* reveal, появление */
--ease-inout: cubic-bezier(.76, 0, .24, 1)   /* переходы страниц, маски */
--ease-snap:  cubic-bezier(.2, .9, .1, 1.05) /* text-button, курсор */

--d-micro: 160ms   hover, фокус
--d-short: 320ms   подчёркивания, строки
--d-med:   640ms   reveal блоков
--d-long:  1100ms  интро hero, переход страниц
```
Stagger строк: 70ms. Stagger букв: 18ms. Ничего дольше 1.4s, кроме интро.

### 7.2 Правила

- **Все scroll-анимации — `scrub` (true или 0.6–1).** `toggleActions` с `play none none none` запрещён.
  Если эффект триггерный (reveal), то `toggleActions: "play reverse play reverse"`.
- Smooth scroll: **Lenis**, синхронизирован с `ScrollTrigger.update` через `gsap.ticker`. На тач-устройствах — нативный скролл (`syncTouch: false`).
- Одновременно двигаются максимум 2 слоя на экране: главный и параллакс-фон.
- Анимируются только `transform`, `opacity`, `clip-path`, uniform'ы шейдера. Не `top/left/width`.
- Интро Home (один раз за сессию): чёрная плашка уходит вверх clip-path → мега-имя проявляется построчно
  из маски → hero-объект «собирается» из displacement 60 → 0 → плавающие фото въезжают по одному с
  поворотом → навигация последней. Всего ≤ 2.2s. Повторный визит — 0.6s короткая версия.
- Переходы страниц: полноэкранная плашка `--void` с displacement-краем (SVG-маска) накрывает снизу вверх
  (550ms), смена роута, уход вверх (550ms). Назад по истории — то же движение в обратную сторону.
- Курсор (только `pointer: fine`): точка 8px `--ink`, над фото — подпись Mono `VIEW`, над ссылками — растёт до 40px с `difference`.

### 7.3 Видеоскролл

- Секция `pin` на 300vh (desktop) / 200vh (mobile). Видео 8–15 сек.
- Основной метод: **последовательность кадров** (WebP, 1280px, ~120 кадров desktop / 640px, 60 кадров mobile)
  на `<canvas>`, индекс кадра = прогресс scrub. Плавно в обе стороны, без проблем seek в Safari iOS.
- Альтернатива для лёгкого режима: `<video muted playsinline preload="auto">` с перекодировкой
  all-keyframe (`-g 1`) и `currentTime` по scrub — только десктоп Chromium.
- Фолбэк: `Save-Data`, `deviceMemory < 4`, reduced-motion → три постер-кадра с crossfade по скроллу.
- Поверх видео — Mono-подписи этапов процесса (`01 RESEARCH → 04 BUILD`), меняются по прогрессу.

### 7.4 prefers-reduced-motion

- Отключить: Lenis, WebGL-дисторшн, параллакс, интро, displacement hover, анимированное зерно.
- Оставить: opacity-фейды ≤ 200ms, состояния hover (цвет/подчёркивание), видеосекцию заменить постерами.
- Pin-секции раскрыть в обычный поток.

## 9. Accessibility

- Контраст текста ≥ 4.5:1 (`--ink-3` на `--paper` проходит; `--ink-4` для текста запрещён).
- Фокус: `outline: 2px solid var(--ink); outline-offset: 4px`, на `--void` — `--on-void`. Никогда `outline: none` без замены.
- Семантика: один `h1` на страницу, `nav`, `main`, `footer`, skip-link «К содержимому».
- Split text: исходная строка в `aria-label`, разбитые span — `aria-hidden`.
- Декоративные канвы/видео — `aria-hidden="true"`; содержательные фото — осмысленный `alt` на русском.
- Мобильное меню: `aria-expanded`, ловушка фокуса, `Esc` закрывает, кнопка меняет текст `MENU`/`CLOSE`.
- Форма: `label` связаны с полями, ошибки через `aria-describedby`, `aria-live="polite"` для статуса.
- `lang="ru"`; английские вставки — `lang="en"`.

## 10. Архитектура

### Стек

- **Vite + React 18 + TypeScript** — статическая сборка, быстрый dev, лёгкий деплой на GitHub Pages.
- **React Router** (`createBrowserRouter`, `basename: "/PROSTI/"`). Vite `base: "/PROSTI/"`.
- **GitHub Pages SPA fallback:** `public/404.html` сохраняет путь в `sessionStorage`/query и редиректит на `/PROSTI/`;
  `index.html` восстанавливает путь до монтирования роутера. Альтернатива на этапе деплоя — копия `index.html` в `404.html` после билда.
- **GSAP 3 + ScrollTrigger + SplitText** (бесплатны с 3.13) — scrub, pin, обратимость.
- **Lenis** — smooth scroll.
- **OGL** (~25 KB) — WebGL-дисторшн; без three.js.
- Стили: CSS Modules + глобальные токены в `src/styles/tokens.css`. Без UI-китов.
- Деплой: GitHub Actions → `actions/deploy-pages`. CNAME не нужен (домена нет).

Почему не Next/Astro: нет SSR-требований, сайт — анимационная SPA; Vite проще на Pages и даёт
полный контроль над переходами между страницами.
